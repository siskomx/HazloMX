# HazloMX

A Windows-first, open-source desktop interface for AI-assisted DIY and engineering workflows, planned around Rust and Tauri.

## Status

Planning and feasibility review. No application has been implemented yet.

The proposed scope includes Codex, Claude, Ollama, and OpenAI-compatible providers; an MCP gateway; permission-controlled application installation and source builds; and engineering integrations for CADCraft, FreeCAD/CADPilot, Arduino Agent, KiCad/Konnect, and OrcaSlicer.

Repository identities, licenses, provider access, and Windows compatibility remain subject to verification. The 24-week roadmap, acceptance criteria, and first sprint are being reviewed in the Codex chat **HazloMX — development plan and feasibility review**.
