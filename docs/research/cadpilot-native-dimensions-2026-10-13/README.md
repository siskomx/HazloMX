# CADPilot native box dimensions

CADPilot inspection now includes native length, width and height in millimeters for Part::Box objects. The selected-box form and labels use these values, even when a different object was the target of the previous operation. Changing one size can preserve the measured other sizes; metric/inch form changes preserve physical values. World bounds remain available as separate spatial measurements and never fill a box's intrinsic dimensions.

The real rotated-box gate creates a 10 × 20 × 30 mm box at (5, 6, 7) mm rotated 45 degrees about Z. Its measured world X/Y extents are about 21.213 mm, while inspection reports the original native 10/20/30 lengths. A separate inch-based copy edit reads back 12.7/25.4/7.619999999999999 mm, preserves placement/source bytes and verifies saved native/STEP geometry. Both cases pass. Reproduce with `rtk proxy python tests/cadpilot/copy_probe.py --rotated`.

All three actual CADPilot Rust gates pass: selected-copy adapter/native and STEP readback, approved workflow/publication/recovery, and owned-process cancellation. The adapter gate also rejects forged, text-valued and zero native dimensions; Rust binds the three positive finite dimensions to measured volume. The verifier now captures source hashes before execution and checks them afterward. Reproduce with `rtk proxy python tests/cadpilot/verify_adapter.py`.

All 115 regular Rust tests, all-target custom-protocol Clippy with warnings denied, frontend TypeScript/Vite build and all nine headless browser workflows pass. Browser tests select a different box with rotated bounds, require native lengths instead of bounds or another object's parameters, and preserve legacy explicit edit-parameter fallback. Old reports without native dimensions remain readable; a fresh inspection supplies values for other objects. A pending proposal whose preview lacks these newly measured values must be prepared again if the native comparison differs.

The assertion now compares native values to the exact approved inch conversion; production dimensions and tolerances were unchanged by that correction. The initial rotated artifacts are retained separately. The workflow and rotated directories retain their own scoped valid results.
