Agents should explain these measurements, clarify the desired change and convert confirmed inputs into the existing drawing's units.

Hazlo validates the published artifacts, captures and inspects that source again, checks its hash/project/runtime, and presents the usual preview and one-use human approval. Cancellation reaches the existing owned inspection process; a cancelled inspection cannot publish a proposal.
