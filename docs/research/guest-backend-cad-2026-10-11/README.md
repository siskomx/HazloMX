# Offline guest backend and FreeCAD checks

Prepare from the repository root with `rtk proxy python apps/desktop/tests/prepare-disk-full-sandbox.py --native-cad C:/absolute/path/FreeCADCmd.exe`. This builds the current library test executable, copies its process fixture/VC runtime and the three geometry source files, and creates a 2 GiB guest configuration with networking disabled. The pinned FreeCAD folder is mapped read-only; only owned evidence output is writable. No SDK, AI model or credentials are copied into the guest.

Start/connect the generated owned guest. If its LogonCommand does not run, execute the mapped `C:\HazloProbe\input\probe.ps1` once with `wsb exec --run-as ExistingLogin`. Read `native-cad-result.json` and the individual logs. The full script deliberately tests accented private profiles; this build-26100 volume cannot provide their ASCII short aliases, so its two launcher/workflow tests fail and the aggregate result stays false. All 38 backend regressions and eight real geometry/failure tests pass. The first attempt's report had a nested-script variable collision and is retained only as invalid evidence. The fixed script isolates that scope, keeps failures false and now exits nonzero for a failed aggregate.

Run the separate mapped `ascii-profiles.ps1` to test supported ASCII private configuration paths. Its test-only `HAZLOMEXA_TEST_ASCII_PROFILES=1` flag changes only the private profile names in the two ignored native tests; accented project/output names and every geometry/publication/recovery assertion stay the same. Both actual backend tests pass in that mode. Default test behavior remains the accented-profile case; the app has no such flag or automatic fallback. No Windows short-name policy was changed.

`identity.json` distinguishes the original test binary used for the failing accented case and the rebuilt test binary used for ASCII mode. The fixed macro and geometry fixture hashes are retained too. These are direct production backend/adapter checks; they do not certify the installed GUI cancellation wiring. The guest was stopped after exporting the logs.
