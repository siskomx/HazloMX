# KiCad application checks and exports

October 11, 2026. The app source offers explicit project capture, one-use approval, KiCad 10.0.7 ERC/DRC, exports, nonreplacing publication and history recovery. [Identified runtime and report gate](../kicad-runtime-2026-10-11/README.md). Konnect editing remains unimplemented.

Select **Revisión y exportación · KiCad**, the official Windows x64 `kicad-cli.exe`, and report coordinates in mm, inches or mils. The native folder/file pickers select the source boundary and principal schematic or PCB. Import captures and hashes the schematic hierarchy, matching project/board/schematic, custom rules, local library tables and their resources, and custom worksheets referenced by project settings. Missing, external, remote, reparse or unsupported library-provider references are rejected. Input is bounded to 1,024 files, 32 MiB per file, 256 MiB total and a 256 KiB proposal manifest. Stock symbol/footprint libraries use the private identified runtime configuration. This 2D workflow does not capture 3D model resources.

The preview lists captured paths, operation and report units. Changing a pending operation requires cancelling and preparing another. Spanish conversation gathers intent without model dispatch. Approval runs fixed commands on private copies; PCB checks refill and save only the working board. Working dependencies are relocated with relative paths, so the retained checked project does not depend on the temporary workspace. Imported original bytes remain unchanged. Schematic outputs are PDF and XML netlist; board outputs are selected copper/mask/silkscreen/outline Gerbers and Excellon drills in millimetres.

All flat runtime binaries are checked against the frozen official package manifest and pinned during execution. Runtime library directory ancestry is pinned, but individual stock library data files are not hashed or held immutable. Fixed subprocesses use the owned Windows supervisor, private configuration/profile, bounded responses and 120-second per-call timeout. Output manifests bind originals, checked files, reports and exports by hash, reject missing or unlisted outputs, and fit the recovery metadata limit. Schema 6 reuses existing project publication and recovery. Recursive verification occurs while the stage is pinned before the existing identity-checked DELETE-handle transition and nonreplacement rename.

File validation and design findings are separate. Completing and publishing a run does not mean ERC/DRC passes. **Ver hallazgos** displays errors, warnings, excluded findings and disabled checks from the verified report. **Ver informe ERC/DRC** displays literal bounded read-only JSON; reports over the dialog's 64 KiB limit remain available in the project. **Mostrar copia revisada** and **Mostrar exportaciones** select their locations in Explorer; they do not launch an editable KiCad session.
