# Embedded native PCB inspection — October 15, 2026

The desktop's existing PCB connection and inspect_selected_live_pcb tool now use the official-client worker embedded in the application. They no longer require selecting Konnect or KiCad CLI to read an open board. Saved-copy checks and edits retain their existing runtimes and approvals. Native PCB writes remain unavailable through chat until their approval/job path and real editor acceptance are complete.

The host sends a fixed inspect request through private stdin with an explicit environment. It retains owned-process cancellation and timeout, validates the exact request UUID, response version, native instance/document/whole-state hashes, component identities and bounded coordinates, and returns no native paths or token. The worker reads the current native model; saved-file bytes cannot satisfy the connection. Chat context carries native state hashes and still declares mutations unavailable.

Desktop builds embed the frozen worker directly. The build refuses an artifact whose executable hash or worker/build-source/lock hashes differ from its receipt. Development and packaging commands prepare or reuse that checked artifact. First-time developer preparation requires Windows x64 CPython 3.11; the application uses the bundled interpreter. The runtime caches the helper by executable hash, verifies its exact bytes under a retained file pin and reuses it across reads. Requests, native tokens and raw stdout/stderr are not persisted by this route.

Verification: the desktop-feature production backend selected a controlled native board, performed a second inspection through the actual host tool, reused one cached helper, refused a tampered helper, kept saved bytes unchanged and created no editing job/history. Its observations then fed the existing frozen-worker native move/readback fixture. Twelve Python worker cases pass with actual local NNG/protobuf, the embedded desktop backend and the release Rust verifier. The separate unreachable-editor host test passes without saved-file fallback or token persistence. All 154 regular desktop-feature Rust tests pass (55 ignored); desktop Clippy, production frontend build and chat regression fixtures pass.

These are controlled-server and source-build proofs. The owned KiCad GUI remains at Updates & Privacy for the person's choices. Real visible PCB edit/readback/follow-up, native undo, concurrent UI edit behavior, approved mutation jobs and the updated installed package remain unfinished. Raw builds, models, test roots and logs stay in ignored target output.
