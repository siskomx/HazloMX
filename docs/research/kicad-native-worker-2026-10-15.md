# Internal KiCad native worker — October 15, 2026

The native PCB worker now exists in apps/desktop/src-tauri/resources/kicad/live.py. It uses the pinned official KiCad Python client and the [verified 10.0.7 transaction wire contract](kicad-transaction-contract-2026-10-15.md). Native inspection is now connected through the [embedded desktop worker](kicad-embedded-inspection-2026-10-15.md); mutation remains internal. Host approval/job routing and real editor acceptance remain unfinished.

The worker identifies the exact open PCB through native document specifiers, pins the native process token by a returned hash and reads complete in-memory board snapshots. Two snapshot reads must agree around component inspection. It returns bounded component summaries and hashes; native document paths, tokens and full board contents are not returned. No saved-file fallback, save, hardware action or generated Python is accepted.

For a move, it rechecks instance, document and whole-board state; refuses locked/unknown-lock components; validates the proposed identity, old coordinates, range, precision and physical change; then begins an explicitly document-bound native commit. The actual SDK moves the footprint and its contained items. The worker checks the returned item and sends the before/after native snapshots to Hazlo's existing Rust whole-board verifier before committing. That verifier requires every part of the board except the approved footprint position to remain unchanged. The worker rechecks the snapshot after host verification and then rereads the committed native result. A change during verification stays uncertain without a blind rollback. Multi-request isolation from concurrent user edits is not yet proved and remains a gate before enabling writes. Export/save and broader PCB operations are not implemented here.

The tools helper now has bounded internal stdin modes for movement validation and whole-board verification. They parse data and return only a boolean; they do not open files, edit native documents or expose source/error contents. Normal agent mode retains its authenticated pipe connection. Snapshot verification reuses the existing parser and movement validator rather than creating another geometry checker.

Confirmed local validation failures before commit trigger a native drop followed by exact snapshot rollback verification. Lost, malformed, foreign-document or otherwise unconfirmed native replies stay uncertain: the worker sends no blind drop or retry. A failed commit/readback or rollback is not reported as a completed change. NNG request retransmission is disabled and incoming native messages are bounded. This does not prove exactly-once delivery under peer disconnects; host lifecycle and uncertain-write reconciliation are still required before enabling the tool.

Verification includes ten worker tests with real SDK objects and the actual built Rust verifier, plus the real local NNG/protobuf protocol probe. Tests cover the public SDK board/version wrappers, a normalized 25.4 mm shift and preserved pad/reference offsets, stale identity/state, invalid precision/range/no-op, locks, unrelated changes, partial updates, rollback failure, lost/malformed replies, post-commit readback failure, duplicate fields and sanitized response envelopes. The NNG probe also accepts the absent item-response header used by native 10.0.7 while refusing an explicitly foreign document header. The actual release helper passes its authenticated MCP catalog, connection and idle-revocation test. These use an in-memory native server; no actual KiCad board was edited. Regular Rust tests pass: 153 passed, 53 ignored. Clippy passes.

The owned KiCad editor still waits at Updates & Privacy for the person's choices. Its real positive IPC, visible edit/readback/follow-up, native undo, cancellation, runtime integration, provider and current installer gates remain unverified. Other named integrations remain required by the full application goal. Raw models, runtime installs, paths and logs stay private in ignored build output.

Native response behavior was checked against the pinned [GetItems handler](https://github.com/KiCad/kicad-source-mirror/blob/10.0.7/pcbnew/api/api_handler_pcb.cpp) and [UpdateItems handler](https://github.com/KiCad/kicad-source-mirror/blob/10.0.7/common/api/api_handler_editor.cpp). Successful item replies omit the optional header; snapshot replies explicitly copy their requested document. Requests still bind the selected document.

The worker now also has a tested standalone Windows build using pinned, hashed Python client and build-tool wheels. The build script is tests/kicad/build_worker.py; it accepts an existing Windows x64 CPython 3.11 executable and keeps installs, binary output, receipts and raw build logs under target. Its frozen self-check confirms imported modules and SDK package metadata. The current desktop build embeds this worker for native inspection; an updated installer has not been tested.

The eleven-case Python suite now includes the actual frozen executable, a local NNG server, official SDK/protobuf packets and the built release Rust verifier. Separate worker processes inspect and move the same native fixture, retain the private process/document binding, receive native-format headerless item replies, perform exactly one begin/update/commit and return a verified unsaved result. This is transport acceptance against a controlled server, not proof of a visible KiCad editor change.

Hazlo's existing owned-process runner now supports bounded private stdin. Real subprocess tests verify a full-limit round trip and EOF, refusal above the limit and cancellation while the writer is blocked and descendants hold its pipe open. Existing callers continue using the same no-input wrapper. The desktop now uses this private dispatch for inspection. Mutation approvals/job routing and updated installed acceptance remain required.

The standalone build follows PyInstaller's documented [operating modes](https://pyinstaller.org/en/stable/operating-mode.html) and [metadata collection options](https://pyinstaller.org/en/stable/usage.html).
