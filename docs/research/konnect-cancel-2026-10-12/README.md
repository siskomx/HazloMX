# Konnect schematic and PCB startup cancellation

Two actual approved workflows pass cancellation after the owned Konnect 0.13.0 SDK server is independently observed alive: a schematic value edit and a PCB component move, both with inch context and identified KiCad 10.0.7. Production dispatch uses its normal private profiles, closed project copies, official SDK transport and owned process job. No UI input, model inference or hardware operation occurs.

The retained schematic sample observed PID 19744 and returned Cancelled in 90 ms; the PCB sample observed PID 26740 and returned Cancelled in 104 ms. Each PID independently ceased, no artifact directory was published, report access was refused, and the consumed approval could not be reused. All four selected project source files remained byte-identical. Closing the Workflow and reopening each project recovered exactly one Cancelled run. See [schematic receipt](schematic/cancel-evidence.json), [PCB receipt](pcb/cancel-evidence.json), retained projects and [49 exported file hashes](file-hashes.json).

Reproduce with `rtk python tests/konnect/verify_cancellation.py`. Its exact ignored Rust fixture must pass and emit two receipts, one for each document type. [Status, source/runtime hashes and command](status.json), [stdout](stdout.log), [stderr](stderr.log) and [tested runner](tested-source/tests/konnect/verify_cancellation.py) identify the gate. Separately, the current 114 regular Rust tests pass with 34 explicitly ignored entries, and all-target custom-protocol Clippy passes. This change adds test/evidence code; production Konnect execution is unchanged.

These samples cover cancellation during SDK startup after observing its live owned server. They do not prove cancellation after initialization during a pending tool call, interruption after a confirmed mutation, exact native UI latency, full production deadlines or live editing of an unsaved KiCad document. Those requirements remain unfinished; original preservation and nonpublication here do not substitute for them. The installer rebuild still awaits closure of the open Hazlo test window, and native input remains stopped following Escape.
