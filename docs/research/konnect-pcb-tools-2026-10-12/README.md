# PCB inspection, reviewed moves and saved-result follow-ups

Hazlo's shared MCP catalog now has twelve tools. `inspect_selected_pcb` reads the explicitly selected saved board with bounded paging. It reports measured references, values, footprints, board sides, UUIDs and millimeter positions without granting filesystem access. `propose_pcb_move` takes that selection/component identity and a confirmed destination in millimeters, inches or mils. The existing desktop approval and Konnect/KiCad executor perform the change; the agent cannot approve it.

After completion, `read_verified_result` revalidates the published native artifacts. Its job ID and report hash can be supplied together to PCB inspection and the next proposal. Hazlo derives the next source from the final KiCad-saved board, captures another copy and requires fresh approval. The original selection and prior results remain unchanged. Missing pairs, unknown identities, stale source bytes, injected paths and altered result hashes are refused.

The actual release helper/SDK gate applies two approved moves through Konnect 0.13.0 and KiCad 10.0.7: J1 moves from `(200.8, 156.6)` to `(203.34, 155.33)` mm using inch inputs, then to `(205, 155.33)` mm using mil inputs. The second proposal's measured starting position comes from the first operation's final saved board. Both schema-12 MCP histories recover after reopening. Original sources and the first published board remain byte-identical. [Calls and readbacks](calls.json), both retained artifact directories/run snapshots and [status](status.json) record the test; [file hashes](file-hashes.json) bind the evidence.

Imperial conversion exposed a persisted-float mismatch. Accepted destinations are now recorded at KiCad's existing six-decimal millimeter precision before approval. Validation still rejects positions beyond that precision; existing KiCad project JSON serialization and historical saved results remain compatible. A regular recovery check covers the inch conversion.

Validation: 110 regular Rust tests pass, 32 integration entries remain separately scoped; the actual two-edit PCB test passes independently. Installed Claude's restricted missing-login boundary also passes ([updates](claude-updates.json)); neither check claims a signed-in model turn.
