# Controlled installed native cancellation

Installer `1c4ea36a…` passes a controlled native UI cancellation check against the actual KiCad CLI 10.0.7. This supplements the [successful native KiCad/recovery checks](../native-recovery-kicad-2026-10-13/README.md), without reclassifying their completed cancellation attempt as a pass.

Additional ordinary and larger-board attempts completed before a usable live cancellation window was confirmed. The larger owned fixture adds 50,000 native track segments to a copy of the existing board, keeping its dependencies in a separate folder; its PCB is 6,871,302 bytes. No original fixture or production code was modified. Successful execution of that board alone does not establish full design correctness or cancellation behavior.

To make the UI cancellation test repeatable, a test-only observer briefly suspends one actual native `pcb drc` child. It first checks an awaiting-approval job UUID and the exact owned installed parent process. It selects only that parent's direct child with the exact KiCad executable, `pcb drc` arguments and matching job UUID. A sixty-second watchdog resumes the child if necessary. This creates a controlled observation window; it is not evidence about cancellation timing during uninterrupted computation.

After explicit UI approval, the observer confirmed and suspended the owned DRC process. Clicking Hazlo's `Cancelar` displayed `Operación cancelada`, persisted a cancelled job, and caused the child to exit after 6.39 seconds of test suspension. The observer exited successfully without its watchdog needing to resume anything. There was no published folder for that job and no new published artifact file. All 92 earlier artifact files and four cancellation-source files remained byte-for-byte unchanged.

[The sanitized receipt](checks.json) records identities, conditions and independently checked outcomes. Raw process identifiers, paths, profiles, captures and project files remain private. The executed observer is retained as [a workspace-relative test fixture](../../../apps/desktop/tests/native-kicad-cancel-observer.py), with additional UUID validation; checks confirm it refuses invalid UUIDs and terminal jobs before changing processes. It requires Python with `psutil`, the owned native UI test project's pending proposal and the installation receipt. It is a manual acceptance fixture, not a production component or a general process pauser. UI input used the computer-use skill after explicit user authorization.

This proves installed UI cancellation dispatch, owned-process termination and nonpublication under the documented paused-child condition. Uninterrupted DRC cancellation timing, cancellation across every adapter, signed-in conversations, live unsaved editing and the other seven native UI workflows remain unfinished. The full application goal stays active.
