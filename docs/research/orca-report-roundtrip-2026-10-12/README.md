# Inch-based Orca publication and recovery survive JSON persistence

The new Orca connector acceptance preflight exposed a real failure: the metric jobs completed, but an inch job sliced successfully and failed publication because its readback dimension `9.999992370000001` differed by a floating-point bit after JSON parsing. Persisted mesh bounds had the same issue during source verification/recovery. The original [failed run](failed-run.json) and untampered native `fixture/` are retained; the failed phase is not rewritten or promoted.

Orca's shared stored-value comparison now accepts either the actual native/source measurement or the exact value obtained by encoding that actual value with Hazlo's JSON writer and decoding it with its parser. It adds no geometric tolerance and changes no global serde configuration. Mesh recapture, source/settings verification and final report comparison share this rule. Original-source hashes, mesh signatures, settings, layers, G-code bytes and all artifact hashes still have to agree.

The regular regression reads the retained actual inch run and 3MF. It demonstrates the numeric mismatch, validates the persisted report/capture, and refuses micrometer changes to bounds/height, changed layer count, changed bed setting and a wrong G-code hash. All **113 regular Rust tests**, formatting and all-target desktop Clippy pass.

The new `installed_orca_workflow` example passes a **host preflight** of four real OrcaSlicer 2.4.2 jobs through the supplied release connector: metric/inch 10 mm cubes, initial 45°C settings and result-bound 50°C follow-ups. It rejects stale report hashes, 201°C and extra path fields; requires one-use shared-backend approval; verifies 50 layers, native outputs, source/profile/prior-result preservation and two-job recovery per unit. `host-preflight/` retains both projects/tool calls. It performs no inference or printer control and does not operate GUI approval.

The reusable online Sandbox preparer/harness includes the fifth example, read-only Orca runtime mapping, explicit stock Prusa machine/process/PLA profiles, metric/inch STL fixtures, four-job verification and project-preserving uninstall. The rebuilt `705532b4…` package now passes [actual installed Orca follow-ups/recovery and lifecycle](../installed-orca-2026-10-12/README.md). Native profile discovery/pickers, signed-in interaction and broader printer/material combinations remain unfinished. The full goal stays active.
