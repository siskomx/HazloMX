# Approve checking a retained copy without repeating its edit

`propose_result_checks` prepares a separate, current human approval for one unused native check attempt on a confirmed retained PCB copy. It binds the original job/input digest, immutable edit checkpoint, current task/revision, saved conditions and existing attempt count. The two-attempt allowance is not reset or expanded. Changed or unlinked copies and exhausted allowances remain preserved and paused. The agent receives a proposal identity, not an execution token.

The new schema-19 operation only invokes the installed KiCad reader against the retained copy in a fresh verification context. It never launches Konnect, repeats a movement, captures today's source or reconnects to the original editor. Before the check, the attempt records its new approval job and input digest. An incomplete attempt cannot be repeated under that consumed approval; missing completion links do not adopt plausible output. Later valid checked results and their standalone approval reports recover locally without native calls. Legacy optional fields remain omitted.

The host detects the compatible existing reader automatically. Chat presents the check-only scope, the remaining resource bound, native copper-zone recalculation/export effects and preservation/physical limits. An incoming check-only proposal selects the appropriate chat route even if the previous tool was different; the person does not locate executables or select the program. Stop and corrections use the existing dispatch barrier. Saved conditions remain locally reviewable, and metadata identifies the original checked result for follow-up. Neither approval nor recovery grants sharing of raw results or other references.

Original checked artifacts publish before the new check report is accepted. Startup considers original jobs before dependent check reports; execution excludes its own active stage from that offline publication scan. A lost dependent report reconstructs only the same linked report. The new report is evidence of the scoped check, not proof of the whole task, electrical correctness or physical function.
