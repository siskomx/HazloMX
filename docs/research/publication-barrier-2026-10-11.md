# Installed publication barrier verification

The installed publication/cancellation overlap passed with actual FreeCAD output and the current release installer. [Retained evidence](installed-publication-2026-10-11/status.json) records native Cancel input during the hold, explicit release, final Completed state, preserved prior outputs and independent host hashes for all 23 closed-export files. This fixture holds a real artifact's data-read open without modifying the production application or fixed macro.

Microsoft documents that a [batch oplock requires acknowledgment before an incompatible operation proceeds](https://learn.microsoft.com/en-us/windows/win32/api/winioctl/ni-winioctl-fsctl_request_batch_oplock). An open requesting only attributes does not normally break an oplock; a data-read open does, and [the batch break precedes sharing checks](https://learn.microsoft.com/en-us/windows-hardware/drivers/ifs/irp-mj-create2).

`tests/fixtures/publication_barrier.rs` compiled and its host self-check passed: the same `symlink_metadata` operation used by the adapter leaves the oplock intact; a data-read open with the publication code's sharing/reparse flags signals a break and remains blocked until the fixture closes its handle; file bytes stay unchanged. The OVERLAPPED allocation intentionally lasts for this short-lived process, preventing asynchronous kernel access to a dropped stack allocation. Only one oplock is requested per invocation.

The normal mode is restricted to WDAGUtilityAccount and a UUID stage under `C:\HazloGuestProject\.hazlomexa\staging`. It waits for the STEP file, requests the FCStd oplock, records granted/broken/released timestamps to the owned probe output and waits at most ninety seconds for a guest-local release signal. It does not change artifact bytes. A separate guest observer confirmed CAD process cessation and a successful matching result while persisted state was Running and no destination existed. The installed Cancel button was clicked before explicit release; the app then displayed verified, published files and persisted Completed.

The first attempt exceeded its original thirty-second fixture deadline and is retained as failed evidence. The corrected guest-local release completed six milliseconds after its explicit request. Host click timestamps and guest timestamps are separate clocks; their ordering is not used as a synchronization proof. The sequential held-observation, native click and guest release establish input overlap. This does not instrument the exact backend command-dispatch instant or the indivisible rename syscall. Existing backend arbitration tests and native pre-publication cancellation cover cancellation winning before commitment. Unexpected readers or a missed acquisition must fail an attempt, not count as publication coverage.
