# Stop source inspection from chat — October 13, 2026

The production chat's existing Stop button now stops initial FreeCAD/CADPilot, CADCraft, Orca source metadata and native PCB inspections. Windows file dialogs keep their own Cancel button; chat Stop becomes available after source selection, when native inspection starts. Progress distinguishes selecting sources, inspecting and stopping. This does not enable native UI automation or change the engineering programs' editing scope.

Each inspection has an opaque ID, one shared cancellation signal and the exact project UUID/folder captured before picking. Only one source inspection can run at a time. The worker retains its guard until native work returns, including errors or cancellation, then releases it. Existing native process supervision and read deadlines remain authoritative. The four source selectors pass that signal through their existing readers.

Cancellation and publication of the selected-source capability share one lock. An accepted Stop prevents publication and preserves earlier selections. A completed publication wins over a late Stop, which returns false rather than claiming to undo an already finished selection. Dropped or copied-project inspections cannot publish. Native PCB source-switch locks are acquired before any prior capability is cleared. No source-inspection approval, engineering job or operation-history entry is created. Partial inspection files remain private; cancellation does not delete user data.

The frontend receives the operation ID only from its own current event channel. It can issue Stop while the inspection command is busy, waits for any outstanding cancellation reply before accepting a result, and discards a late result after accepted cancellation. Stale channel events cannot cancel a newer inspection. A failed cancellation request remains an error rather than a fabricated success. The new command is restricted to the bundled main window and is not an agent tool; the shared catalog remains at 26 tools.

It also verifies wrong IDs, overlap refusal, expired guards, cancelled Orca metadata inspection, prior schematic preservation, copied-UUID folder refusal and no new job/history.

Konnect uses a fresh explicitly nonexistent endpoint; the user's editor is never contacted. This is a headless reader cancellation test, not a native UI test or positive live editor observation.
- The production browser suite covers all four Stop flows, source/context preservation, no model turn or approval during inspection/cancellation, stale events, successful late-result refusal, late Stop after completion, picker cancellation and normal return to chat. Existing 36 provider/operation result-handoff cases remain passing. The history suite, isolated legacy form fixture, frontend typecheck/build and desktop binary/example compilation/Clippy also pass. The legacy drawing fixture supplies the newly required event channel without changing its superseded form behavior.

Actual native CADCraft source-inspection cancellation, native Windows dialogs/Stop interaction, installed behavior and ordinary-user acceptance remain unverified. Orca inspection is metadata reading; this gate does not run a slicer or establish slicing cancellation. The old installer predates this source and needs rebuilding. Real-agent conversations, positive editor/session/revision binding, live edits and the full cross-program goal remain unfinished. Native UI automation is still paused after Escape.
